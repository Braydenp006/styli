# Button

Buttons trigger actions: one `sty-btn--primary` (honey) per screen at most, `--secondary` for other actions, `--ghost` for low-emphasis ones like Cancel, and `--danger` for destructive ones.

Use `<button class="sty-btn sty-btn--primary">`. Labels are sentence case verbs ("Convert now"). Minimum height 40 px; on touch screens give the row enough room to reach 44 px targets. Disabled buttons use the `disabled` attribute.
